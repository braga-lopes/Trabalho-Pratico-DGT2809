# Livraria Virtual — Trabalho Prático DGT2809


## Como rodar

1. Descompacte esta pasta em algum lugar do seu computador (ex: `Downloads`)
2. Abra o terminal (PowerShell) dentro da pasta
3. Instale as dependências:
   ```powershell
   npm install
   ```
4. Se nescessário:
   ```powershell
   npm install --force
   ```
5. Rode o projeto:
   ```powershell
   npm start
   ```
6. Rodar como administrador:
   ```powershell
   ng serve
   ```
7. Espere aparecer `✔ Compiled successfully` no terminal
8. Abra o navegador (Chrome/Edge) e digite na barra de endereço:
   ```
   http://localhost:4200
   ```

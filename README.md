# Livraria Virtual — Trabalho Prático DGT2809


## Como rodar

1. Descompacte esta pasta em algum lugar do seu computador (ex: `Downloads`)
2. Abra o terminal (PowerShell)
3. Instale as dependências:
   ```powershell
   npm install
   
   npm install --force
   ```
4. Rode o projeto:
   ```powershell
   npm start
   ```
5. Rodar como administrador:
   ```powershell
   ng serve
   ```
6. Espere aparecer `✔ Compiled successfully` no terminal
7. Abra o navegador (Chrome/Edge) e digite na barra de endereço:
   ```
   http://localhost:4200
   ```
